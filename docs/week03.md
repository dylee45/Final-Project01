## 3주차 - 통행 판단 알고리즘 구현 및 시각화

### 작업자 : 20231066 이도영

### 작업 내용

- 경사로 통행 판단 모듈 분리 및 구현
- 경사로와 계단, 장애물의 위치 관계 분석
- Bounding Box 기반 장애물 겹침 비율 계산
- YOLO 모델의 지원 클래스 확인 기능 구현
- 경사각 및 장애물 탐지 결과를 활용한 V/X/? 판단 기능 구현
- Streamlit 분석 결과 및 판단 사유 표시
- 지도 마커 색상 및 V/X/? 표시 기능 구현

### 통행 판단 기준

- V: 추정 경사각이 기준 이내이고 겹치는 장애물 후보가 탐지되지 않은 경우
- X: 계단만 탐지되거나 경사각 기준을 초과하거나 장애물 겹침 비율이 30% 이상인 경우
- ?: 경사각 추정 실패, 장애물 일부 겹침 또는 판단 정보가 부족한 경우

### 테스트 결과

- 통행 판단 단위 테스트 13개 전체 통과
- 실제 사진을 활용한 경사로 및 계단 탐지 확인
- X 및 ? 판단 결과 출력 확인
- 지도 마커 연동 확인

### 향후 작업

- 장애물 탐지를 지원하는 YOLO 모델 통합
- 경사각 추정 기능 개선 결과 연동
- 실제 사진을 활용한 V 판단 및 장애물 분석 검증

※ 장애물 겹침 비율 30%는 프로젝트의 임시 판단 기준.

# 1주차 개발 기록

## 1. 개발 목표

YOLO Object Detection 실행 환경을 구축하고,
경사로 탐지 및 GUI 기본 기능을 테스트한다.

## 2. YOLO 개발 환경 구축

- Python, PyTorch, Ultralytics 설치
- YOLO11n 기본 객체 탐지 테스트
- Roboflow 경사로 데이터셋 준비
- YOLO11n 경사로 모델 초기 학습 (5 Epoch)
- 경사로 탐지 결과 및 신뢰도 확인

## 3. GUI 및 지도 시각화

- Streamlit 기반 GUI 기본 화면 구현
- 이미지 업로드 및 미리보기
- 샘플 분석 결과 표시
- Folium 기반 지도 표시
- 지도에서 위치 선택 기능 구현

※ GUI 분석 결과는 샘플 데이터이며,
실제 YOLO 모델과 연동되지 않은 상태이다.

## 4. GitHub 협업

- 기능별 브랜치 생성
- 코드 Commit 및 Push
- Pull Request 및 Merge 진행
- SourceTree를 활용한 작업 이력 관리

## 5. 향후 작업

- YOLO Detection 함수 모듈화
- 실제 사진을 이용한 탐지 테스트
- 모델 성능 개선
- GUI와 탐지 기능 연동

# 휠체어 사용자를 위한 경사로 탐지 및 통행 조건 분석

## 1. 프로젝트 소개

YOLO Object Detection과 Segmentation을 활용하여
사진 속 경사로와 장애물 후보를 분석하고,
결과를 지도에 표시하는 프로그램입니다.

## 2. GUI 및 지도 시각화
본 프로젝트는 YOLO11 Object Detection을 활용하여
사진 속 경사로, 계단 및 장애물 후보를 분석하고,
휠체어 통행 가능 여부를 판단하여 지도에 시각화하는
프로그램 개발을 목표로 합니다.

사진을 업로드하면 YOLO 탐지, 경사각 자동 추정, 지도 표시를 한 화면에서 실행할 수 있습니다.

## 4. 실행 방법

### GUI 실행

1. 학습한 YOLO 가중치 `best.pt`를 프로젝트 최상위 폴더에 복사합니다. 기존 `runs/detect/ramp_final/weights/best.pt`, `ramp_test_v2`, `ramp_test` 아래 가중치도 자동으로 찾습니다. 다른 위치를 쓸 경우 화면의 **분석 설정 → YOLO 모델 경로**에 경로를 입력합니다.
2. 프로젝트 최상위 폴더에서 다음 명령을 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run gui_map/app.py
```

3. 사진을 올리고 **사진 분석 실행**을 누릅니다. 경사각 계산에 필요한 점은 자동으로 선택됩니다.
4. 지도에서 촬영 위치를 선택하고 **지도에 분석 결과 표시**를 누릅니다. 마커는 현재 앱 세션에 표시됩니다.

깊이 모델은 경사로가 처음 탐지됐을 때 다운로드하므로 인터넷 연결이 필요합니다.
사용한 YOLO 가중치가 학습한 클래스만 탐지할 수 있습니다. 예를 들어 2클래스 모델은 `ramp`와 `stairs`를 탐지합니다.

### YOLO 기본 환경 테스트

```bash
python detection/test_detection.py
```

### 경사로 탐지 모델 학습

```bash
python src/train.py
```

### 학습된 모델로 객체 탐지

```bash
python detection/predict.py --model runs/detect/ramp_final/weights/best.pt --source datasets/final/test/images
```

※ 학습 및 탐지 명령어는 필요한 데이터셋과 모델 파일이
로컬에 준비된 경우 실행할 수 있습니다.

## 사진 기반 경사각 자동 추정

- `src/analysis.py`는 YOLO 탐지 결과와 깊이 모델을 연결합니다.
- 자동 분석은 경사면과 기준 바닥의 깊이 표본에 각각 3D 평면을 맞추고 **추정 종단 경사각**을 출력합니다. 입구선을 검출하면 기준 바닥 평면에서 입구선에 직각인 방향을 씁니다. 평면을 직접 맞추는 경로는 바닥 표본 중심에서 경사면 표본 중심으로 향하는 방향을 사용합니다.
- 부호는 기준 바닥에서 경사로 안쪽으로 향할 때 오르막(+) 또는 내리막(-)으로 추정한 결과입니다. 경사 기준과 비교할 때는 절댓값을 씁니다. 입구선 검증에서는 2° 미만도 기존 표본과 깊이 검사를 거쳐 평가합니다.
- 경사로 끝과 그 앞의 평평한 바닥이 함께 보이는 사진을 사용합니다. 바닥이 잘렸거나 두 표면을 충분히 찾지 못하면 추정 불가로 표시합니다. 상자에 다른 평면이 크게 포함되거나 기준 바닥이 기울어져 있으면 오차가 생길 수 있습니다.
- 기본 가로 화각은 60°이며 실제 카메라 화각에 맞춰 조정할 수 있습니다. 팀에서 정한 경사 기준을 입력하면 결과를 비교합니다. 계단·장애물 후보는 현장 확인 항목으로 표시하며, 사진만으로 실제 휠체어 통행 가능 여부를 확정하지 않습니다.

## 사진 기반 경사각 수동 추정 (비교용)

### 구현 내용

- `ramp_angle/estimate.py`: 단일 사진의 깊이 추정 및 경사각 계산
- Depth Anything V2 Metric Outdoor Small 사전 학습 모델 사용
- 경사로와 기준 바닥 영역을 사용자가 직접 선택
- 선택한 진행 방향의 종단 경사각과 두 평면 사이 각도 계산
- 가로 화각 45°, 60°, 75° 조건별 결과 출력 및 JSON 저장

기존 수동 스크립트는 자동 추정 결과와 비교할 때 사용할 수 있습니다.

### 사용 모델 및 각도 계산 방식

- 모델: Depth Anything V2 Metric Outdoor Small
- Hugging Face ID: `depth-anything/Depth-Anything-V2-Metric-Outdoor-Small-hf`
- 사전 학습된 모델을 추가 학습 없이 사용하여 사진의 깊이를 추정합니다.
- 추정 깊이와 가정한 카메라 화각을 이용해 3차원 좌표를 복원합니다.
- 사용자가 선택한 경사로와 기준 바닥에 각각 평면을 맞춘 뒤,
  선택한 진행 방향의 종단 경사각을 계산합니다.

※ 모델이 경사각을 직접 출력하는 방식이 아니라,
깊이 추정 결과에 기하 계산을 적용하는 방식입니다.

### 개발 환경

- Python
- PyTorch, Transformers
- NumPy, Pillow, Matplotlib

### 실행 방법

**1. 가상환경 생성**

프로젝트 최상위 폴더에서 실행합니다.

```powershell
python -m venv ramp_angle/.venv
```

**2. 라이브러리 설치**

```powershell
.\ramp_angle\.venv\Scripts\python.exe -m pip install -r ramp_angle/requirements.txt
```

**3. 사진 분석**

```powershell
.\ramp_angle\.venv\Scripts\python.exe ramp_angle/estimate.py --image "사진경로.jpg" --out results_test
```

`사진경로.jpg`는 분석할 사진의 실제 경로로 변경합니다.
최초 실행 시 사전 학습 모델을 다운로드하므로 인터넷 연결이 필요합니다.

### 영역 선택 방법

사진 창에서 총 10개의 점을 순서대로 선택합니다.

1. 경사로 바닥 안쪽의 네 점을 사각형 둘레 순서로 선택합니다.
2. 수평으로 확인된 기준 바닥 안쪽의 네 점을 선택합니다.
3. 경사로 영역 안에서 낮은 지점, 높은 지점 순서로 두 점을 선택합니다.

경사로와 기준 바닥 영역은 겹치지 않도록 선택하고,
벽, 난간, 경사로 옆면은 제외합니다.

현재 선택 단계에서는 마우스 오른쪽 버튼으로 마지막 점을 취소할 수 있습니다.
필요한 점 개수를 모두 선택하면 다음 단계로 이동합니다.

### 결과 확인

- `종단 경사각`: 선택한 진행 방향을 따라 계산한 경사각
- `두 평면 사이 각도`: 경사로와 기준 바닥 평면 사이 각도
- 계산 결과는 터미널에 출력되며, 지정한 출력 폴더에 `result.json`으로 저장됩니다.

화각을 직접 지정할 수도 있습니다.

```powershell
.\ramp_angle\.venv\Scripts\python.exe ramp_angle/estimate.py --image "사진경로.jpg" --out results_test --fov 60
```

### 테스트 결과 및 한계

실측 경사각을 확인한 사진 6장으로 테스트한 결과,
5장에서는 실측값과 유사한 추정값을 얻었으며,
정면에서 촬영한 1장에서는 경사각이 크게 추정되었습니다.

이를 통해 촬영 구도에 따라 추정 오차가 달라질 수 있음을 확인했습니다.
향후 정면 사진에서 발생하는 과대 추정 현상을 분석하고 개선할 예정입니다.

- 현재 결과는 실험적인 추정값이며, 휠체어 통행 가능 여부를 확정하는 기준으로 사용하지 않습니다.

# 사진 기반 경사로 탐지 및 경사각 추정

Streamlit에서 사진을 업로드하면 YOLO 모델로 경사로와 기준 바닥을 찾고, 두 영역의 깊이 정보를 이용해 경사로의 각도를 추정합니다.

## 1. 패키지 설치

Windows PowerShell에서 프로젝트 루트 폴더(`finalproject`)를 열고 실행합니다.

```powershell
python -m pip install -r requirements.txt
```

## 2. GUI 실행

**표본 범위 확장** 옵션이 코드에 있는지 확인하려면 아래 명령을 실행합니다.

```powershell
Select-String -Path ".\gui_map\app.py" -Pattern "표본 범위 확장"
```

같은 터미널에서 GUI를 실행합니다. 브라우저가 자동으로 열리지 않으면 터미널에 표시된 `Local URL`을 엽니다.

```powershell
python -m streamlit run ".\gui_map\app.py"
```

## 3. 사진 업로드 및 분석 설정

사진을 업로드하고 **분석 설정**을 펼친 뒤 아래 값을 입력합니다. 모델 경로는 프로젝트 루트 폴더 기준입니다.

YOLO 모델 경로 : `runs/detect/ramp_final/weights/best.pt` 
기준 바닥 모델 경로 : `runs/segment/ramp_seg/weights/best.pt` 
경사로 분할 모델 경로 : 밑에서 추가로 설명했습니다.
경사면 분할 신뢰도 기준 (%) : `20` 
프로젝트 경사 기준 사용 : 켜기. 표시되는 **프로젝트 경사 기준 (°)**에 팀에서 정한 값을 입력합니다.
카메라 가로 화각 (°) : `60` 

### 경사로 분할 모델 선택
`runs/segment/ramp_mask/weights/best.pt` :**끄기** ( 기본 실행 설정입니다.)
`runs/segment/ramp_mask_e20/weights/best.pt` : **켜기** (20 epoch 학습 모델입니다. 테스트에서 경사면이 더 깔끔하게 분할된 사진도 있었지만, 경사각 추정 오차가 커진 사례도 있었습니다. 이 모델을 사용할 때는 표본 범위를 확장합니다.)

설정을 마친 뒤 **사진 분석 실행**을 누릅니다. 모델을 찾을 수 없다는 메시지가 나오면 입력한 경로에 해당 `best.pt` 파일이 있는지 확인합니다.

## 카메라 화각 가정

테스트 사진의 촬영 조건에서 확인한 가로 화각은 약 56°였으며, 현재 설정에서는 60°를 가정해 경사각을 추정합니다. 향후 사진에 화각 계산에 필요한 정보가 있으면, 이를 바탕으로 사진별 가로 화각을 계산하는 기능을 추가할 수 있습니다.
